# v8.0.4 Release Notes

## What Changed

- Raised the `SpeakSwiftly` dependency floor to `9.0.2`.
- Raised the `TextForSpeech` dependency floor to `0.22.1`.
- Added a repo-wide security audit report under `docs/security-audits/`.
- Added roadmap follow-up tracking for the audit's addressable local-surface findings.
- Removed the plugin-managed `PermissionRequest` hook probe so the shipped Codex hook payload only registers the `Stop` TTS hook.

## Breaking Changes

- None for `SpeakSwiftlyServer` patch consumers.

## Migration Notes

- Consumers can update normally through SwiftPM. The server API shape is unchanged.
- Operators who track the Codex plugin payload should use the `v8.0.4` release after the release workflow updates the plugin manifest and Socket hook cache paths.

## Verification

- Pending release validation through `scripts/repo-maintenance/release.sh --mode standard --version v8.0.4`.
