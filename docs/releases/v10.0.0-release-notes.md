# v10.0.0 Release Notes

## What Changed

- Raised the `SpeakSwiftly` dependency floor to `10.0.0`.
- Raised the resolved `mlx-audio-swift` dependency to `0.100.0` through the `SpeakSwiftly` update.
- Added next-start runtime configuration support for `duck_media_volume` with `off`, `a_little`, `default`, and `a_lot` values.
- Exposed `duck_media_volume` through the HTTP `PUT /configuration` payload, MCP `set_runtime_configuration` tool schema, persisted YAML config, and runtime configuration snapshots.

## Breaking Changes

- None for `SpeakSwiftlyServer` consumers.

## Migration Notes

- Existing configs continue to default media ducking to `off`.
- Operators can stage media ducking by setting `app.runtime.duckMediaVolume` in `server.yaml` or `duck_media_volume` through the runtime configuration API. The setting takes effect on the next runtime start.
- Enabling any media ducking value other than `off` may require macOS Automation permission so SpeakSwiftly can lower and restore supported media app volumes during local speech playback.
