# v5.0.6 Release Notes

## What Changed

- clarified Speak Swiftly docs and skill guidance so normal installs use plugin-managed Codex hooks only
- documented user-level Speak Swiftly hooks as duplicate or legacy repair targets, not fallback hooks
- tightened LaunchAgent skill guidance so live-service refresh stays separate from plugin upgrade and does not require hand-editing Codex hook or MCP config

## Breaking Changes

- None for `SpeakSwiftlyServer` patch consumers.

## Migration And Upgrade Notes

- Upgrade the Speak Swiftly plugin payload and restart Codex so plugin-managed lifecycle hook guidance reloads.
- Keep normal Speak Swiftly hook setup in the installed plugin-managed `hooks/hooks.json` payload.
- Do not add a user-level `~/.codex/hooks.json` Speak Swiftly hook for normal installs.
