# v5.0.9 Release Notes

## What Changed

- Bumped the Codex plugin manifest to `5.0.9`.
- Aligned Socket-managed hook cache paths in the plugin hooks, hook doctor, hook documentation, and Codex Hooks skill guidance to `5.0.9`.
- Updated the release version-bump script so future bumps move the manifest and versioned Socket hook cache paths together.

## Breaking Changes

None.

## Migration And Upgrade Notes

- After upgrading the Codex plugin, the Socket-managed hook command paths should resolve through the `5.0.9` plugin cache payload.
- The existing native Swift service install is not changed by the plugin manifest bump.

## Verification

- No local tests or CI were run for this manual release.
