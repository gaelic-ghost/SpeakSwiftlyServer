# v5.0.1 Release Notes

## What Changed

- bumped the server's exact `SpeakSwiftly` dependency pin to `5.0.1` and its direct `TextForSpeech` baseline to `0.21.0`
- aligned HTTP, MCP, embedded, and Codex hook request-context surfaces with the slim `RequestContext` shape: `source`, `topic`, `attributes`, `cwd`, and `repo_root`
- moved former app, agent, project, and client-display provenance into request-context attributes where that signal is still useful
- lightened remote GitHub CI by adding `scripts/repo-maintenance/validate-ci.sh`, which keeps package build and tests while skipping DocC, CLI smoke, SwiftFormat, SwiftLint, and Homebrew tool installation on PR checks

## Breaking Changes

- None for `SpeakSwiftlyServer` patch consumers.

## Migration And Upgrade Notes

- HTTP, MCP, and hook callers should stop sending `app`, `agent`, and `project` inside `request_context`; put caller-specific labels under `request_context.attributes` instead.
- Local maintainers should continue using `sh scripts/repo-maintenance/validate-all.sh` before release handoff. Remote CI now uses `bash scripts/repo-maintenance/validate-ci.sh`.

## Verification Performed

- `xcrun swift package resolve`
