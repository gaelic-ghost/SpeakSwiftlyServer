# Default Voice Samples

This directory holds short public preview samples of package-owned default voices.

Keep these samples separate from Gale's personal saved voice profiles. Each audio file should have
enough nearby metadata for a maintainer to know what voice it represents, where it came from, and
whether it is safe to keep in a public repository.

## Metadata Checklist

- profile name
- seed id when the sample represents a package built-in
- transcript
- voice description
- source kind
- generation command or request ID when available
- consent and license note
- generation date
- package commit or release used to generate it
